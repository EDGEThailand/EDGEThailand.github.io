# EDGE Thailand — ชุดพร้อมอัปโหลด GitHub Pages
อัปเดต 4 ตุลาคม 2569

## วิธีนำเว็บขึ้น GitHub
1. แตก ZIP บนเครื่องก่อน ไม่อัปโหลด ZIP ทั้งก้อน
2. อัปโหลดไฟล์และโฟลเดอร์ภายในทั้งหมดไปที่ระดับบนสุดของ repository ให้ index.html อยู่ระดับบนสุด พร้อม assets และ data
3. หากเป็น repository เดิม ให้แทนที่ไฟล์ชื่อเดิม
4. Settings → Pages → Deploy from a branch → เลือก main และ / (root) → Save
5. รอ GitHub แสดงลิงก์เว็บไซต์ แล้วเปิดตรวจ หากยังเห็นข้อมูลเก่าให้รีเฟรช

เว็บเป็น HTML/CSS/JavaScript ไม่ต้องติดตั้งหรือ build รองรับที่อยู่แบบ repository subpath มี .nojekyll

## สิ่งที่พร้อมใช้งาน
- ข้อมูลสมาชิก 80 ราย ทำเนียบต้นฉบับ 36 ราย เปิดอ่านและดาวน์โหลดได้
- ค้นหาสมาชิก/ธุรกิจ และกรองหมวดข้อมูล
- ตัดนาย นาง นางสาว และรูปย่อจากชื่อที่แสดงบนเว็บ แก้อรคมเป็นอาคมแล้ว
- PDF/JPG ทำเนียบต้นฉบับและภาพตัวอย่างคงเนื้อหาตามเอกสารที่สมาชิกจัดทำ
- ปุ่มติดต่อ/รับข่าว เชื่อม Google Form ของโครงการ
- ทุกปุ่มแจ้งข้อมูล/แก้ไขทำเนียบ เชื่อม Google Form สำหรับอัปเดตข้อมูล
- ทั้งสองฟอร์มเปิดแท็บใหม่ สมาชิกส่งคำขอให้ทีมงานตรวจ ไม่ได้แก้เว็บอัตโนมัติ
- โลโก้ต๋องเปาเปิดเพจ Facebook ที่ผู้จัดระบุ

## ดูแลข้อมูลภายหลัง
config.js เก็บลิงก์แบบฟอร์มทั้งสอง
ทีมงานดูคำตอบใน Google Forms ของตน ตรวจข้อมูล แล้วแก้ data/members.js และไฟล์ใน assets/profiles ก่อนอัปโหลดเข้า GitHub
ไม่ต้องเปิดสิทธิ์แก้เว็บให้สมาชิก ไม่ต้องเผยแพร่ชีตคำตอบ
รูปสินค้าและรายละเอียดเพิ่มเติมสามารถเติมภายหลังได้

## แหล่งข้อมูล
ใช้รายชื่อ Excel ชีต รวม และไฟล์ทำเนียบที่ผู้จัดส่ง ภาพและโลโก้จากผู้จัด
เนื้อหาจุดเริ่มต้นและแหล่งทุนตามข้อความที่ผู้จัดยืนยันล่าสุด
ตัวเลขปี 2568 และเรื่องไอศกรีมผักจาก report TH 26feb2026.pptx สไลด์ 5–6 และ 18–19
ไม่มีสัญญาหรือ Excel ต้นฉบับในชุดเผยแพร่ ไม่ใช้โลโก้ EDC/Bank of America
ฟอนต์ Google Fonts มีฟอนต์ระบบสำรอง
